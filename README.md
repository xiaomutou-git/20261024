# TRAE 社区 · 1024 程序员节 3D 互动页

一个为 1024 程序员节做的三维互动页：中央是体素拼成的社区标志，标志里的两只眼睛由 `10` 与 `24` 的点阵组成——连起来读就是 **1024**；四周环绕社区成员的像素头像，按住可以汇聚成 **TRAE**，继续按住还会在背后用粒子展示相册。

## 功能

| 交互 | 效果 |
| --- | --- |
| 拖拽 / 滚轮 | 旋转与缩放场景 |
| 点击方块 | 点亮并触发能量脉冲 |
| 按住 ≥0.32s | 四周头像的像素汇聚成 TRAE，拖动不打断 |
| 按住 ≥5s | TRAE 背后用粒子拼出相册图片，约每 3 秒切换（旧图散成粒子、新图聚拢） |
| 松开 | 粒子淡出，恢复中央标志 |
| 右上色块 | 6 套配色：科技青 / 矩阵绿 / 暖橙 / 霓虹紫 / 宣纸白 / 石墨灰 |

背景常驻效果：竖列下落的 0/1 数字雨、偶尔掉落的竖排祝福语、页面上方横向飘过的社区技巧。

## 技术栈

- three.js（WebGL 三维渲染）
- 原生 ES Module + Vite（构建与开发服务器）
- 无后端、无接口调用、无第三方统计

## 本地运行

```bash
pnpm install
pnpm dev      # 开发服务器，默认 http://127.0.0.1:5178
pnpm build    # 生产构建，输出到 dist/
pnpm preview  # 预览生产构建，默认 http://127.0.0.1:4173
```

## 关于图片素材

仓库**不包含** `image/` 与 `image2/` 两个目录，原因是里面是社区成员的真实头像与照片（合计约 32MB），不适合随公开仓库分发。

缺少这两个目录时页面仍可正常运行：

- `image/` 为空 → 所有头像回退为按账号名生成的确定性像素头像；
- `image2/` 为空 → 跳过"按住 5 秒"的粒子相册。

想在本地看到完整效果，请自行把图片放进去：

```
image/     头像（png / jpg / jpeg / webp / avif），文件名建议与成员昵称一致
image2/    粒子相册图片（png / jpg / jpeg / webp / avif）
```

两个目录都是按文件名自动收集的（`import.meta.glob`），无需改代码。

## 目录结构

```
src/
  core/       三维场景核心：体素场、头像墙、数据雨、粒子相册、技巧飘带
  data/       数据：社区成员、官方收录技巧、相册图片清单
  ui/         HUD：状态栏、主题切换、社区抽屉
  styles/     样式与主题令牌
index.html    页面骨架与降级内容
vite.config.js
```

## 性能上的几个取舍

- 体素使用单个 `InstancedMesh` 绘制（639 个点阵格 × 5 层 = 3195 实例）；
- 头像每个是一张 `InstancedMesh`（64 实例），共用几何体与材质；
- 相册图片在**解码阶段**就缩到 84px 高，每张只采样一次并缓存；
- 昵称标签按需创建，不在构建期生成 220 张纹理；
- 刻意不做泛光/辉光，单色图形保持纯色；
- 渲染像素比上限 1.5（移动端 1.25），降低填充率与发热；
- 支持 `prefers-reduced-motion`，开启后冻结所有飘动效果。

## 无障碍

- 画布提供降级内容：WebGL 不可用时展示静态介绍，不影响信息获取；
- 交互均有键盘可达的替代入口（顶栏按钮）；
- 尊重系统的"减弱动效"偏好。
